features:
  - title: Blocking control
    details: Toggle Pi-hole blocking on or off from the popup, or temporarily disable it for a preset duration so it re-enables automatically.
  - title: Domain management
    details: See whether the current tab's domain is blocked or allowlisted and toggle it instantly, without opening the Pi-hole admin interface.
  - title: Stats
    details: View today's query count, blocked count, block percentage, and cache hits, each with a 24-hour sparkline.
  - title: System info
    details: See uptime, CPU load, memory usage, and temperature at a glance in the popup.
  - title: Groups and lists
    details: Enable or disable blocking groups and individual blocklists directly from the popup.
  - title: Multiple Pi-holes
    details: Connect to multiple Pi-holes and switch between them with per-instance tabs in the popup.
